# plist

Agent-friendly project status registry.

## Status folders

- `live/` — in production
- `active/` — currently being worked on
- `planning/` — being scoped or designed
- `planned/` — approved but not started
- `concept/` — retained idea, no commitment yet
- `priority/` — current attention queue; priority is independent of lifecycle status

Project records are JSON. Keep changes small, explicit, and commit-traceable.
